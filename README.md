# 🌱 Eco Recife

Dashboard interativo para mapeamento e visualização de dados sobre a educação ambiental nas escolas de Ensino Fundamental e Médio de Recife.

## 🛠️ Stacks utilizadas

- **HTML5**: estrutura das páginas;
- **CSS3**: estilização e responsividade;
- **JavaScript**: interatividade e lógica do dashboard;
- **Chart.js**: criação dos gráficos e visualização dos dados;
- **GitHub**: versionamento de código e colaboração;
- **Vercel**: hospedagem e deploy.


## 🌐 Deploy

O projeto é publicado automaticamente na **Vercel** a cada push na branch principal do GitHub.

## 🎨 Atualização: interações nas caixas
